# 🔥 Event Booking System (MERN Stack)

> A full-stack **Event Booking Platform** with authentication, admin controls, seat tracking, and a modern UI.

---

## 🌐 Live Demo

👉 https://capstone-project-final-eotx.onrender.com/

---

## 🚀 Features

✨ User Authentication (Register / Login)  
👨‍💼 Admin & User Roles  
📅 Create & Manage Events (Admin only)  
🎟️ Book Events with Real-time Seat Count  
📊 Seats Tracking (e.g. `12 / 50 booked`)  
🧾 View & Cancel Bookings  
🔍 Search & Filter Events  
📆 Upcoming & Past Events Separation  

---

## ⚙️ How It Works

1. User registers or logs in  
2. Admin can create events  
3. Users can:
   - Browse events  
   - Book seats  
   - View bookings  
4. Seats update dynamically  
5. Events automatically categorized into:
   - Upcoming  
   - Past
